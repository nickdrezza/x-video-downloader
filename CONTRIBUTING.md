# Contributing

Small, focused pull requests are welcome.

1. Fork the repository and create a branch.
2. Run `./scripts/build.sh`.
3. Install the runtime dependencies with `brew install yt-dlp gallery-dl ffmpeg`.
4. Log into the target site in a supported browser, then launch the app and test mode selection, URL parsing, browser-cookie selection from the app menu, folder selection, image/video downloads, compression targets, file dropping, and cancellation.
5. Open a pull request describing the behavior changed and how it was verified.

Please do not commit downloaded videos, build output, credentials, cookies, or personal paths.
